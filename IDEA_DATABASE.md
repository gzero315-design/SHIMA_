# IDEA_DATABASE.md

# Banco de Ideas Maestro

## Objetivo

Repositorio de premisas para historias tipo Gneef.

Cada idea debe:

- Basarse en una única regla.
- Ser explicable en una frase.
- Escalar naturalmente.
- Tener potencial visual.
- Permitir un giro final.
- Ser evaluable mediante SCORING_SYSTEM.md.
